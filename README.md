# ニケシミュ / NIKESMI

勝利の女神：NIKKE のアリーナ（5vs5）向けの編成シミュレータです。
2つの編成を組むと、バーストゲージが貯まって B1→B2→B3 が繋がり、フルバーストが開き、
ダメージが積み上がって、どちらかが全滅するまでを 1/60 秒刻みで再現します。

ブラウザで `index.html` を開くだけで動きます。ビルドもサーバーも要りません。

## できること

- **編成** — 自チームと相手チームを5人ずつ。クリックでもドラッグでも入れられます
- **自動計算** — キャラを入れた時点で計算が走ります。実行ボタンはありません
- **勝率** — 乱数を変えて60回試行した割合。決着時間の中央値も出ます
- **タイムライン** — チームの残りHP。開くとキャラごとのHP推移、バーストしたキャラ、撃破の連鎖が並びます
- **育成の再現** — レベル・限界突破・コア強化・好感度・スキルLv・魔方・装備・コレクション・オーバーロードを個別に設定できます
- **編成の保存** — 名前を付けて保存し、いつでも呼び出せます
- **アカウント同期** — BlablaLink から所持ニケと育成状況を取り込めます

```
└ 再生バー ─ 再生 ・ シーク ・ 速度
```

## 計算していること

```
最終ダメージ =
  (最終攻撃力 − 最終防御力)          ← 防御力無視ダメージは引かない
  × 倍率（武器倍率 / スキル倍率）
  × (1 + 会心 + フルバースト)         ← この括弧の中は加算
  × 有利コード（1.1）
  × チャージ倍率（RL / SR の通常攻撃のみ）
  × 与ダメージ群（攻撃・バースト・持続・貫通 … 加算）
  × 被ダメージ群
```

- 同じ群の中は**加算**、群をまたぐと**乗算**。防御力は**減算**します
- **アリーナにコアヒットはありません。適正距離補正もありません**
- 属性は5すくみ。有利なときだけ +10% で、不利でも軽減されません
  （灼熱→風圧→鉄甲→電撃→水冷→灼熱）
- 会心は 15% / +50% をシード付き乱数で判定
- バーストゲージはヒット単位で貯まります。SGは10ペレット、RLは爆風が届いた
  ニケと遮蔽物のぶんだけ加算されます
- ゲージMAXから約0.43秒でB1、以降 約0.53秒間隔で B2, B3。B3 のあと10秒フルバースト
- ゲージはバースト連鎖が始まってからフルバーストが終わるまで貯まりません
- バーストの連鎖は編成の左優先。バーストのクールタイム中・戦闘不能のキャラは飛ばします
- スキルは本文から発動条件・対象・効果を読み取って実行します

### アリーナ別

| モード | レベル | 戦闘力補正 |
|---|---|---|
| チャンピオン | 400固定 | なし |
| ルーキー | 実際のレベル | あり |
| スペシャル | 実際のレベル | あり（編成ごと） |

戦闘力補正は、相手の84.6%を下回ったときにステータスが20%減り、
差が開くほど最大90%まで減ります。

## まだ正確でないところ

ゲームのスキル文から効果を自動で読み取っているため、特殊な状態変化
（専用スタック、モード切替、デコイ、遮蔽物の耐久など）は一部しか再現できていません。
そうした効果を持つキャラは実際より弱く出ることがあります。

相手の育成状況は本来分かりません。標準的な育成を仮の値として置いているので、
実際の相手が極端に硬い／柔らかい場合は予測が外れます。

**絶対的な勝ち負けの予言ではなく、同じ条件で2つの編成を見比べる道具として使ってください。**

大会の実戦記録（チャンピオンアリーナ、1万件あまり）と照合すると、編成だけから
勝敗を当てる精度は五分五分でした。実際の対戦では同じキャラでもプレイヤーごとの
育成度が違い、こちらからは見えません。このツールは全員を同じ標準的な育成として
扱うため、「どちらの編成が噛み合っているか」は比べられても、
「この相手に実際勝てるか」までは言い切れません。

## 画像について

`assets/portraits/` に顔画像を置いています（リポジトリには含めていません）。
別の場所に置く場合は `js/config.js` の `PORTRAIT_BASE` を書き換えてください。

```
js/config.js
  window.PORTRAIT_BASE = 'https://example.com/portraits/';
```

画像が無くても、キャラ名の頭文字を表示して動作します。

## データの作り方

名簿とスキルの原本はゲームのマスターテーブル（`キャラ+スキル.txt`）です。

```bash
python -I tools/parse_chara_bundle.py     # バンドル -> data/game_master.json（実行はしない。文字列として読むだけ）
python -I tools/compile_skills.py "キャラ+スキル.txt" js/skills.js
python -I tools/build_master.py           # 名簿 -> js/data.js
python -I tools/build_stats_data.py ../work/pvp js/stat_data.js
python -I tools/fetch_portraits.py        # 顔画像
```

## 開発

```bash
node tools/serve.js 5173        # ローカル確認
node tools/test_engine.js       # エンジンの簡易テスト
node tools/validate.js c10 400 3   # 実戦データとの照合
```
