# ニケシミュ

アリーナの編成を、実際に戦わせて確かめるツールです。
2つのチームを組むと、バーストが回ってダメージが積まれ、どちらが崩れるかまでを再現します。

https://icekun0704.github.io/nikesmi/

## 使い方

1. 上の5枠に自分のチーム、下の5枠に相手のチームを入れます
2. 入れた瞬間に計算が始まります。ボタンはありません
3. 結果と、下のタイムラインで「誰がいつバーストして、誰がいつ落ちたか」を見ます

キャラは一覧からクリックでも、枠へドラッグでも入ります。枠の × で外せます。

## 画面の見かた

- **勝率** — 試行を繰り返した割合。1回の結果は運で変わるので、こちらを見てください
- **決着** — 戦いが終わった時間
- **初回フルバースト** — 最初にバースト3まで繋がった時間。ここが速いほど先手です
- **タイムライン** — チームの残りHP。開くと、キャラごとのHP・バーストした瞬間（縦線）・撃破が並びます
- **イベント** — 「誰が誰を倒したか」の一覧。クリックするとその瞬間に飛びます

タイムラインはマウスホイールで拡大できます。←→キーで1フレームずつ動きます。

## 育て具合を合わせる

枠の ⚙ から、レベル・限界突破・コア・スキルLv・魔方・装備・コレクション・オーバーロードを設定できます。
分かる範囲で近づけるほど、結果が実際に近くなります。

レベルはチーム共通です（編成バーの Lv）。チャンピオンアリーナは全員400固定なので、そちらでは変わりません。

## 編成を保存する

「保存」で、いまの5人と育成設定をまとめて残せます。次回は上のプルダウンから呼び出せます。
